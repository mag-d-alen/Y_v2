# Muscle State starts as fully manual annotation; an automated Muscle State estimator is a later phase

Assigning a Muscle State (Working/Lengthening/Shortened/Neutral) to every muscle for every Asana Variant by hand doesn't scale and has no consistent grounding. Instead, each muscle in the Muscle Atlas gets a literature-sourced Muscle Structure and Function record once; per Asana Variant, a future Muscle State estimator computes a candidate Muscle State — length state geometrically from the Rig's Pose Data, working state from a simplified static-equilibrium torque model. A human anatomy expert always confirms or corrects the estimator's candidate Muscle State before it becomes part of a Muscle Annotation — the estimator only ever proposes the Muscle State, never the Muscle Annotation's role sentence, which stays human-authored in every phase, and its output is never the final source of truth on its own. For v1, only the Muscle Structure and Function library and fully manual Muscle Annotation authoring ship; the Muscle State estimator itself is a fast-follow, built once enough confirmed Muscle Annotations exist to validate it against.
