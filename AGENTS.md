## Agent skills

### Issue tracker

Issues and specs are tracked as local markdown files under `.scratch/`, not GitHub Issues — this repo is public, and specs/planning content shouldn't be publicly visible by default, so `.scratch/` is gitignored. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five canonical triage labels unchanged (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
